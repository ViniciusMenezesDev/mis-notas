## Saludos básicos

| Español           | Português           |
|--------------------|----------------------|
| ¡Hola!             | Olá!                |
| Buenos días        | Bom dia              |
| Buenas tardes      | Boa tarde            |
| Buenas noches      | Boa noite            |
| ¿Cómo estás?       | Como você está?      |
| Estoy bien, gracias| Estou bem, obrigado  |
| ¿Y tú?             | E você?              |
| Hasta luego        | Até logo             |
| Hasta mañana       | Até amanhã           |
| Adiós              | Adeus / Tchau        |

## Observações

- `tú` é a forma informal de "você"; em contextos formais usa-se `usted`.
- `¿Cómo estás?` leva os pontos de interrogação invertidos no início (`¿`), uma particularidade do espanhol.
- `gracias` (obrigado/a) não varia por gênero como em português.
